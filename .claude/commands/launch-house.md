# Launch a new Work-It house

Invoke the `launch-house` skill and follow it exactly to create a new Work-It house (household) —
the same mechanism behind The OG, Gowanus, Miami Beach, and Brooklyn.

If arguments were given below, treat them as the house name/details to use; otherwise ask the user
for the house name and whether it should be public-join or invite-only before doing anything, per
the skill's Step 1.
