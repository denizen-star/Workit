## What this is

"Work-It" — a Next.js PWA for a 48-week year (weeks 1–6 are the 4-day upper/lower saddle; week 7+ one lower, Extra Upper, bonus core or class) with belt diplomas, used by a household of users authenticated via **email + 4-digit PIN** at `/login` (no name picker). New-athlete write-up: **`docs/WHAT_IS_WORKIT.md`** (keep it in sync when program rules change). Deployed on **Netlify** at `workitapp.fit` (legacy `workit.kervinapps.com`). New people join at `/join?h=gowanus`. Houses: **The OG** and **Gowanus**. Data lives in PlanetScale (MySQL, serverless HTTP driver). Coach voices: **Master Tom Iron** (`master`), **James Grey** (`james`, Grey for short), and **Luna Meadows** (`luna`; old id `sergeant` still reads). Shouts fill `{name}` with **alias, else first name** (`athleteCallName` / `fillCoachName`). Keep **man** as a type (good men, the man who walked in), not a greeting — awkward titles are `{name}. That is growth.` Prize and punishment are **growth, lean, definition, power, stamina, mobility** (pay or withhold). Not come-home / aftercare / sexual. Tom is implication and control; quit is a noun, not `sissy`. Grey is British want, gym-plain, not office talk. Luna follows the picker too: calm, soft, hard work. Nicole McPherson register. UI tone: **gold** = take this action (Start, Now, Invite, Complete, Resume). **Earth green** (`#6d8b6e`) = done / good. **Earth red** (`#a35d52`) = still a problem. **Copper** (`#c08457`) = the house (avg, pack, You / house). **Cream** = you.

## Architecture

**Auth flow**: Session-based, not NextAuth. `lib/session.ts` issues/verifies an HS256 JWT (`jose`) in the `workit_session` cookie, signed with `AUTH_SECRET` (≥32 chars). `lib/auth.ts` wraps PIN hashing (scrypt), in-memory lockout (resets on redeploy), `requireCurrentUser`/`requireAdmin`, prefs, and house context (`last_household_id`). Login is **email + 4-digit PIN** at `/login` (`POST /api/auth/login`). Name picker is gone. `/` and `/who` → `/home` if session, else `/login`. Unauthenticated pages → `/login`; APIs → 401 JSON. Public: `/login`, `/join`, `/waiver`, `/api/auth/*`, `/api/join`, `GET /api/users`, cron, analytics event. New Gowanus people: `/join?h=gowanus` then verify mail (`/login?verify=`); `/login` blocked until `email_verified_at`. Invitees: `/join?h=…&claim=` (old `/who?claim=` redirects). Forgot PIN mails `/login?reset=`. Invitees created with `pin_hash` NULL. User id `1` is admin of every house he is in. Houses: **The OG** (`og`, invite only) and **Gowanus** (`gowanus`, public join). `migrate-households.sql` (hand SQL; re-run = duplicate).

**Workout program is static**: `lib/workoutData.ts` weeks 1–6 plus `lib/yearProgram.ts` weeks 7–48. Week 2 is gym, not a travel week. Weeks 3–6 add optional **Bonus Upper** (`WorkoutDay.bonus`). Week 7+ bonus is **Bonus Core** or a marked class. Week lock / perfect week = **any 4** completed sessions (`lib/bonusDay.ts` `REQUIRED_DAYS_TO_LOCK`). Home Start, nudges, and `findNextProgramDay` skip bonus; an open bonus session still resumes. Count = one completed bonus per week (Do Again does not increment; detect via `workout_type` containing Bonus + program flag). Home flag hidden if the week has no bonus day; after the last bonus week, keep the tally if count > 0. Rest-between-uppers copy is a hint, not a lock. Travel is a per-session default (`workout_sessions.workout_mode`) plus per-exercise overrides (`workout_sessions.exercise_modes` JSON, keyed by gym name). `lib/travelExercises.ts` substitutions via `applyExerciseMode()` / `applyWorkoutMode()`. Home **Start WO** POSTs `workout_mode=gym`. Select Workout: Gym/Travel pill on unstarted or in-progress days (resume locks the **session** pill). Live cards get their own Gym/Travel pill; it locks after the first completed set on that movement (`PATCH /api/sessions` with `exerciseModes`; incomplete set rows rename). Finished days use `CompletedSessionCard` (same card as the completed log) with a small **Do Again** on the header and actual duration, not Est. Locked weeks (4 finished sessions) start folded (`lib/nextWorkout.ts` `defaultSelectWeek`); an open session opens that week, else the next unlocked week. Restart returns to Start so they can pick again. `/workout?week=&day=` will not create a session if that day is already complete and nothing is open; **Do Again** still starts a new one. Extra sets: +5 cap, copy last completed, **Remove** only on uncompleted extras (`DELETE /api/exercises?id=`). Prefill: set 1 gets the heaviest set (weight + those reps) from the last completed session that had that movement (`lib/setHistory.ts`); sets 2+ stay empty until the previous set is completed, then that load copies forward. Same for timed / bodyweight / distance, extras, and Do Again. Last-time chip shows that heaviest prior set plus its Effort score (`· Effort N`; Fair/3 if that historical set has no recorded hardness). Gain/loss takeover: weight up (any reps) or same weight with more reps = good; same or lower weight with fewer reps = bad; same load, or weight down with reps up, is silent. New all-time weight still shows the PR flash first. **Noise Control** (Edit profile, `users.noise_takeover` / `noise_effort` / `show_prs`, `lib/noisePref.ts`) is three independent on/off switches: post-set gain/loss flash, hardness-call flash, and the New-PR flash. Voting on How hard always happens every set regardless of the switch — only the resulting flash is gated. Off never shows that flash but the record/vote still saves. PRs always land in the recap/completion email no matter the New-PR setting. (A three-way Set/Exercise/Off dial briefly existed; the "once per exercise" level depended on fragile set-completion tracking across extra sets and mode switches and was cut back to plain on/off — any stored `exercise` value now reads as on.) The current (next-to-complete) set gets a gold border, and so does the **How hard?** prompt the first time it appears unvoted, as a "what's next" cue. A timed exercise's Stop button both records the held seconds and completes the set in one tap (no separate Complete Set tap). Finished sets fold gray; tap to edit (yellow **Editing**). Folded row has skippable **How hard?** 1–5 (Easy–Max), locked once tapped (`exercise_sets.hardness`; coach `hardness_1`–`hardness_5` line). Displayed board lb is effort × volume; optional +500 never scaled. Place / week podium / medals / live **Today** bar stay raw. Travel Survivor (`travel_week`) = 4 completed **session** travel-mode days (per-lift overrides do not change that). Best-effort portrait lock (`usePortraitLock`) while a session is open. Rest/set clocks arm `armRestAlarm` / `armSetAlarm` in `lib/playChime.ts`. **Finish it** sits after cooldown on phone and desktop. Last completed lift does not open Finish; it scrolls to cooldown.
