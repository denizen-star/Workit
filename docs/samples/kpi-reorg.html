What this page answers

Who showed up. Who moved the most Volume Load. Who is getting stronger vs last time. Who is grinding harder for the same bar.

Week medals stay Kevin-only honor. They do not replace this board.

Primary

Weight sum — add the load on each completed set (Kevin T-15: 14,444 lb). Weight avg — sum ÷ sets (84 lb). Avg per rep is Volume ÷ reps (87 lb) when you want intensity by rep, not by set.

Rep sum / avg — 2,012 reps · 11.7 per set.

Volume Load — Σ (reps × weight). Set / exercise / session / window. Kevin T-15: 174,758 lb. This is the old “raw iron” without optional +500.

Effective Load — Volume Load × Effort %. Skip How hard = Fair = 60%. Kevin T-15: 124,419 lb. This is today’s Effort-scaled board, named.

Grain

Set Volume Load · Exercise Volume Load · Session Volume Load. Relative Volume Load (vs 1RM) is not in the data yet. Hard sets / muscle uses How hard 4–5. sRPE uses session stars × minutes (Kevin’s last Lower B: 5 × 58 = 291). RPE / RIR is How hard until we store RIR.

Optional +500 and rank

Home keeps trophies, week lock, More load / fewer drops, Daily weight, You vs leader, and a folded Your performance (Current / Progress). The house keeps today’s board and adds a tracking line plus You vs the person you have to beat. Rank stays days, then Volume Load.
